# 表格处理流程

## 何时使用

- 数据脏乱（格式不统一、有重复、有空行）需要清洗；
- 要做汇总、透视、多表合并；
- 要写复杂公式；
- 要批量重命名、转换格式。

## 步骤

1. **先勘察，别急着算**：
   ```python
   import pandas as pd
   df = pd.read_csv("data.csv")
   print(df.shape)          # 行数列数
   print(df.dtypes)         # 类型
   print(df.head())         # 长什么样
   print(df.isna().sum())   # 缺失情况
   print(df.duplicated().sum())  # 重复行
   ```
   发现问题（缺失、重复、类型混乱、明显错误值）**先报告**，不要直接往下算。

2. **明确目标与产出**：清洗？汇总？合并？转换格式？产出的表应该长什么样、给谁用？

3. **写脚本批量处理**（手工处理上百行必然出错）：
   - CSV/Excel 用 Python + pandas；
   - 合并多表：先确认**关联键**，检查键是否唯一、不匹配的记录怎么处理；
   - 统一格式：日期、金额、大小写、去空格——一次定义好规则再全量应用。

4. **Excel 公式场景**：给出可直接粘贴的公式，并逐参数说明。常用：
   - 查找：`XLOOKUP` / `INDEX+MATCH`（优于 `VLOOKUP`，不受列顺序限制）
   - 条件汇总：`SUMIFS` / `COUNTIFS`
   - 文本清理：`TRIM` / `TEXTSPLIT` / `SUBSTITUTE`
   - 提示适用范围与是否需要数组公式。

5. **保留原始数据**：结果写成**新文件**，绝不覆盖原文件。

6. **核对结果**：
   - 处理前后行数变化是否合理（被过滤/合并掉多少）；
   - 关键字段有没有丢或错位；
   - 汇总值能不能与原始数据对上。

## 输出格式

```
## 数据发现的问题
（缺失 / 重复 / 异常，带具体数字）
## 处理方式
## 结果
（文件已交付；行数、关键汇总值）
## 核对结论
```

## 注意

- **不编造数据**。缺失就说明缺失；不要用 0 或平均值悄悄填充（除非用户明确要求，且说明影响）。
- 不覆盖用户的原始文件。
- 敏感数据只做聚合分析，不逐条导出明细。
- 处理完必须核对，不要「跑完就说好了」。
