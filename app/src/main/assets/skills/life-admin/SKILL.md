# 生活事务处理

## 何时使用

- 要办一件事但不知道流程与所需材料；
- 需要在多个方案/服务间比价选型；
- 搬家、采购、行程等需要列清单的事务。

## 步骤

1. **先弄清具体场景**：地点（城市/平台）、时间要求、有无特殊限制。
   **不同地区政策差异很大，不要给通用答案。**
2. **拆成可勾选清单**：每项写清「要做什么 / 需要什么材料 / 去哪办 / 大概多久」。
   ```
   - [ ] 事项 —— 材料 / 渠道 / 时限
   ```
3. **多方案比较**（涉及价格或服务时）：
   | 维度 | 方案 A | 方案 B |
   | --- | --- | --- |
   | 价格 | | |
   | 时效 | | |
   | 条款/限制 | | |
   | 售后 | | |
   给出推荐理由与代价，不只给一个结论。
4. **标出关键节点**：截止时间、需提前预约的、容易卡住的环节、必须本人到场的。
5. **给下一步**：明确用户现在该做的第一件事。

## 输出格式

```
## 事项梳理
## 清单
- [ ] ...
## 方案对比（如适用）
## 关键节点与提醒
## 下一步
```

## 注意

- **不编造价格、政策、办理时限**——这些会变且地区差异大，必须用 `websearch`/`webfetch` 查证并标注来源与查询时间；查不到就写「需自行确认」。
- 涉及合同、法律、税务、保险条款时，提醒需专业意见。
- 不替用户做重大决策（大额支出、签约），给对比与建议，决定权交回。
- 交付文件时用 `writeFile` + `sendFile`。
