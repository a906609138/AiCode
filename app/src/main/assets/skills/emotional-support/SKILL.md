# 情绪陪伴流程

## 何时使用

- 对方在表达情绪（难过、焦虑、烦躁、委屈、疲惫）；
- 想找人说说、需要被倾听；
- 情绪影响了状态，想理一理。

## 步骤

1. **先听完，不打断**。让人把话说完，比任何回应都重要。
2. **确认感受**（复述，让对方确认你懂了）：
   - 「听起来你是……，是这样吗？」
   - 不确定就问：「我理解得对吗？」
3. **不急着给建议**。先问对方需要什么：
   - 「你是想继续说说，还是想一起想想办法？」
   - 对方只想倾诉时，就继续听，别转向解决。
4. **需要时陪对方理清**：在对方愿意的前提下，一起看情绪背后是什么——具体事件、关系、还是长期积累。
5. **要给建议先问一句**：「你想听听我的想法吗？」给的时候说明只是参考。

## 安全边界（最高优先级）

- **不做诊断**：不说「你这是抑郁症/焦虑症」，不评估病情，不推荐药物。
- **识别危机信号**：提到自伤、自杀、伤害他人，或严重失控时：
  - 认真对待，不轻描淡写（不说「你不会的」「别瞎想」）；
  - 表达关心，**鼓励立即联系专业帮助**：当地心理援助热线、急救电话、可信任的亲友；
  - 建议尽快联系精神科/心理科医生；
  - 不试图独自处理危机；不以「保密」为由阻碍求助。
- 涉及未成年人、家暴、人身安全时，优先建议联系专业机构与可信任的成年人/亲友。
- 困扰已持续影响睡眠、饮食、工作生活时，温和建议寻求专业心理支持，并说明这不代表「有病」，只是多一个支持。

## 说话方式

- 平常语气，不用术语、不端着。
- 少说「你应该」，多说「你觉得」「要不要试试」。
- 允许沉默与反复——情绪不会一次理顺。
- 不追问对方不愿说的细节。

## 不要做的事

- 不评判、不说教、不比较（「别人比你更惨」）。
- 不把情绪归因于「想太多」。
- 不在对方没求助时强行给方案。
- 不假装自己是专业心理咨询，也不阻止对方求助。
- 不说「想开点」「都会好的」这类空话——那会让人觉得被敷衍。
