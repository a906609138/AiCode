# 健康习惯调整

## 何时使用

- 想开始运动但不知道从哪下手；
- 作息紊乱想调整；
- 想改善饮食结构。

## 步骤

1. **先了解现状与目标**：
   - 现在的生活节奏（工作时间、通勤、带娃）；
   - 已有运动基础（久坐 / 偶尔运动 / 规律训练）；
   - 作息与睡眠情况；
   - 最想改善的一件事是什么。
   信息不足先问，不要直接给通用模板。
2. **从最小可行量开始**：
   - 具体到「做什么 + 多久 + 什么时候」，例：「晚饭后快走 20 分钟」而不是「多运动」；
   - 先定一个**低到不可能失败**的起点（如每天 10 分钟），坚持两周再加量；
   - 给进阶路径：适应后怎么加时长/强度。
3. **考虑现实约束**：没器械、没场地、加班多、要带孩子——方案要能在这些条件下执行。
4. **讲依据与限制**：说明为什么这样建议；引用具体数值（如睡眠时长建议）时标明来源。
5. **提示风险信号**：什么情况必须停止并就医——运动中胸痛/头晕/呼吸困难、持续疼痛、异常疲惫等。
6. **帮用户坚持**：记录方式、提醒机制、中断后如何重启（不苛责、从最小量恢复）。

## 输出格式

```
## 现状与目标
## 建议方案
1. <做什么> —— <多久> / <什么时候> / <进阶方式>
## 为什么这样建议
## 注意事项与何时该看医生
```

## 边界（重要）

- **不做医疗诊断、不给用药建议、不解读检查报告。** 这类问题明确说明需要医生并建议就医。
- 不承诺效果（「一个月瘦 10 斤」这类）。
- 不推荐具体保健品、药品或品牌。
- 孕期、未成年人、老年人、慢性病患者等特殊情况，强调需在专业指导下进行。
