# 办公文书写作

## 何时使用

- 写周报 / 月报 / 季报；
- 写工作总结、复盘；
- 写汇报材料、请示；
- 写通知公告、会议纪要、工作邮件。

## 通用步骤

1. **先定三件事**：给谁看、要他做什么、多长篇幅。这决定详略与语气。
2. **归类材料**：把零散信息归成 3~5 个要点，按重要性排序。同一层级的要点颗粒度要一致。
3. **结论先行**：最重要的信息放最前面。汇报类尤其如此——领导最关心结论与需要他决策的事。
4. **删一遍**：删重复、删虚词、拆长句。每段都问「读者关心这个吗」。

## 各文体结构

**周报 / 月报**
```
## 本期完成
- （事项 + 结果，尽量带数据）
## 关键数据
## 问题与风险
## 下期计划
```

**工作总结**
```
## 主要成果（带数据支撑）
## 做法与经验
## 存在的不足
## 改进方向
```

**汇报材料**
```
## 结论与建议（先说这个）
## 支撑依据
## 需要决策的事项
```

**通知公告**
```
## 事由
## 具体安排（时间 / 地点 / 要求 / 截止）
## 联系人与联系方式
```

**会议纪要**
```
## 议题
## 讨论要点
## 结论
## 待办事项（事项 + 责任人 + 时限）
```

## 注意

- **不编造数据、成果或时间**。缺的信息用 `【待补充：xxx】` 标出，别猜。
- 不写「高度重视」「进一步加强」这类没有具体动作支撑的套话。
- 对外正式文件（合同、法律文书）要提醒用户需专业审核。
- 信息不全时先写出可用草稿并标出空缺，而不是停下来只问问题。
