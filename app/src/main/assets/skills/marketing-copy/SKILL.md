# 营销文案写作

## 何时使用

- 写产品介绍、卖点提炼；
- 写社媒推文、活动宣传；
- 写广告语、标题。

## 步骤

1. **先确认三要素**（缺一个就写不准）：
   - **受众**：是谁？他们关心什么、痛点是什么？
   - **渠道**：发在哪？决定长度、语气、格式；
   - **动作**：想让人做什么？（点击 / 购买 / 转发 / 关注）
2. **找切入点**：从受众的**具体场景或痛点**切入，而不是从产品功能切入。
   - ❌「XX 智能水杯，采用先进技术」
   - ✅「开会三小时忘了喝水？这个杯子会提醒你」
3. **按渠道套结构**：

   **社媒短文案**
   ```
   [钩子] 一句话抓住注意力（提问 / 反差 / 具体场景）
   [理由] 一个最打动人的点，不要罗列
   [行动] 明确的下一步
   ```

   **产品介绍**
   ```
   [问题] 解决什么麻烦
   [方案] 怎么解决（讲清机制，别堆形容词）
   [证据] 数据 / 案例 / 第三方背书
   [行动]
   ```

   **广告语**：短（≤15 字）、具体、有记忆点。避免「品质卓越」这类空词。

   **长文**：标题决定打开率，前 3 行决定是否读下去，小标题决定读完率。

4. **给 2~3 个版本**，标明各自的切入角度（如「痛点型 / 数据型 / 故事型」），让用户挑或组合。
5. **删一遍**：删形容词、删套话、删重复。每句都问「这句让读者多知道一件事了吗」。
6. **合规检查**：
   - 不用绝对化用语（最、第一、100%、国家级等广告法风险词）；
   - 不编造效果、数据、评价、资质；
   - 医疗、金融、教育等受监管行业提示需合规审核。

## 输出格式

- 直接给成稿，不写「以下是我的文案」这类开场。
- 多版本时标明切入角度，便于对比。
- 缺信息用 `【待补充：xxx】` 标出，不要编。

## 注意

- **不虚构用户评价、案例、数据、资质**。要举例就明确标注是示例。
- 不为了煽动情绪而夸大或制造焦虑。
- 交付文件用 `writeFile` + `sendFile`。
