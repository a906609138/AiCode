# 旅行规划流程

## 何时使用

- 出行前需要设计行程；
- 已有行程想优化节奏或成本；
- 需要在多个目的地/方案间做选择。

## 步骤

1. **先问清约束**（信息不全就排不出能走的行程）：
   - 出发地与目的地、日期与天数；
   - 同行人（老人、小孩会显著影响节奏）；
   - 预算档位；
   - 偏好（自然/人文/购物/美食/休闲）；
   - 必去的地方、必须避开的（如人多、爬坡）。
2. **先搭大框架**：
   - 按**地理位置分区**，每天集中在一个区域，避免来回横穿；
   - 先排「必去」，再把顺路的补进来；
   - 一天最多安排 2~3 个主要景点——超过就走不完。
3. **填具体安排**，每天包含：
   - 时间、地点、交通方式与**实际耗时**（含换乘、排队）；
   - 餐饮建议（就近、符合口味）；
   - **备选方案**：下雨、排队过长、临时关闭时怎么办。
4. **算预算**：交通、住宿、门票、餐饮分项估算，给**区间**而不是假精确的数字。
5. **补实用信息**：证件与签证、天气与穿衣、当地习俗禁忌、常用 App、紧急联系方式。

## 输出格式

```
# <目的地> N 天行程

## 概览
（天数 / 节奏 / 预算区间）

## 逐日安排
### 第 N 天：<主题>
| 时间 | 安排 | 交通 | 备注 |
| --- | --- | --- | --- |

## 预算估算
| 项目 | 估算 | 说明 |

## 实用提醒
## 备选方案
```

## 注意

- **不编造营业时间、票价、班次**——这些必须用 `websearch`/`webfetch` 查证，标注来源与查询时间；查不到就写「需自行确认」。
- 不排不可能完成的行程（一天跨多个城市、每个景点只留 30 分钟）。
- 每天留出机动时间；行程过满会让整趟旅行变成赶场。
- 签证与出入境政策以官方最新公告为准，提醒用户自行复核。
