# 关系沟通梳理

## 何时使用

- 和伴侣/家人/朋友/同事的沟通卡住了；
- 想表达不满但怕一开口就吵；
- 刚发生了冲突，想理清该怎么处理。

## 步骤

1. **先听清处境**：发生了什么、对方的反应、你的感受、你**真正想要**的是什么。信息不全先问，别急着给建议。
2. **把三样东西分开**（这是改善沟通的关键）：
   - **事实**：可观察的具体行为（「这周三次约好的时间你都迟到」）；
   - **感受**：你的情绪（「我觉得不被重视」）；
   - **需求**：你希望得到什么（「我希望约定时间能被当回事」）。
   冲突多半源于把三者混在一起，变成了人身指责。
3. **改写表达**：
   | 常见说法 | 改写方向 |
   | --- | --- |
   | 「你总是……」（泛化） | 说**具体行为**与频率 |
   | 「你根本不在乎我」（定动机） | 说**自己的感受**与触发点 |
   | 「你能不能多关心我」（模糊） | 提**具体、可执行的请求** |
4. **考虑对方立场**：对方可能的顾虑、压力、未被满足的需求。这不是替对方开脱，而是让沟通有落点。
5. **给可执行方案**：
   - 什么时候谈（情绪平复后、私下、时间充裕时）；
   - 怎么开口（先说什么、怎么过渡）；
   - 对方激动或回避时怎么应对；
   - 哪些话题先放一放。
6. **该设边界就设边界**：如果对方持续贬低、控制、越界，明确说这不是沟通技巧能解决的。

## 输出格式

```
## 我听到的情况
## 关键在哪里（事实 / 感受 / 需求）
## 可以怎么说（具体话术）
## 对方可能的反应与应对
## 需要注意的边界
```

## 安全边界

- **不做心理诊断**，不评判任何一方「有病」。
- 涉及**家暴、威胁、人身安全**：明确这不是沟通问题，优先确保安全、联系可信任的人或专业机构（当地援助热线、报警）。
- 涉及法律问题（离婚、抚养、财产）建议咨询专业律师。
- 不替用户决定是否继续这段关系；给视角与选项，决定权交回。
- 不臆测对方动机并当成事实；只基于用户提供的信息。
